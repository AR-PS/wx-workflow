# ar-workflow

Workflow for the Atmospheric River Prediction System (AR-PS)

## 1. Currently supported platforms
-   NOAA RDHPCS Hera
-   NOAA RDHPCS Ursa
-   NOAA RDHPCS Gaea C6
-   MSU-HPC systems (Hercules/Orion)
-   NCAR supercomputer Derecho
-   WCOSS2
